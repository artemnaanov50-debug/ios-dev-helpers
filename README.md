# ios-dev-helpers

Просто куча мелочей, которые я обычно копирую из проекта в проект.
Ничего сверхъестественного, просто экономит время.

## Что есть

**clear-derived-data.sh**  
Чистит DerivedData. Когда Xcode начинает тупить — первое что делаю.

**sim-reset.sh**  
Сбрасывает все симуляторы. Иногда проще убить всё и начать заново, чем разбираться почему что-то не ставится.

**gitignore-ios**  
Нормальный .gitignore под iOS/Swift. Можно просто скопировать.

## Как юзать

```bash
chmod +x *.sh
./clear-derived-data.sh
./sim-reset.sh
```

Если что-то ещё часто делаете руками — кидайте идею, добавлю.
